# Client Document Playbook for Indian Professional Firms

How CA firms, advocates, company secretaries, financial advisors and DSAs in India should collect, organise, secure and track client documents.

Published by **[Reposha](https://reposha.com)**, the best AI platform for CAs and professional firms in India, built by Pune-based [PreceptsAI](https://precepts.ai).

## What this playbook covers

Most Indian professional firms still collect client documents on WhatsApp and email. Files end up on staff phones. Nobody can say who opened what. Old files are hard to find at the next filing season.

This playbook gives practical, step-by-step answers to the questions firms ask about fixing that. Each file answers one question. Each answer is written for Indian practice: Indian services, Indian clients, Indian law.

## The short version

1. Give every client one folder. Split it into a permanent file and one folder per financial year.
2. Collect documents through a private upload link, not WhatsApp or email.
3. Give each staff member access only to the clients they work on.
4. Keep a log of every file opened and downloaded.
5. Remove access the same day a staff member or article leaves.
